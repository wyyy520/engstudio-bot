## 尽快体验

1. 下载对应平台的安装包（[查看下载页](/download)）
2. 按 [安装与部署](/deployment/install) 完成安装
3. 启动 EngStudio，左侧调色板拖入模板节点，连线组织你的工程流水线
4. 点击「运行」，系统自动编译、调度、执行，节点状态实时回传
