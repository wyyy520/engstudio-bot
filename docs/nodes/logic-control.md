# 逻辑控制节点

逻辑控制节点包含条件判断、循环等控制流节点，用于控制工作流的执行流程。

## 条件判断节点 (If-Else)

### 节点信息

| 属性 | 值 |
|------|-----|
| 节点类型 | `if-else` |
| 所属 Domain | `common` |
| 节点分类 | 逻辑类 |

### 输入端口

| 端口名称 | 端口类型 | 是否必填 | 说明 |
|----------|----------|----------|------|
| input | data | 是 | 输入数据 |
| trigger | trigger | 是 | 触发信号 |

### 输出端口

| 端口名称 | 端口类型 | 说明 |
|----------|----------|------|
| true | trigger | 条件为真时触发 |
| false | trigger | 条件为假时触发 |

### 参数配置

| 参数名称 | 类型 | 默认值 | 说明 | 校验规则 |
|----------|------|--------|------|----------|
| condition | string | - | 条件表达式 | 不能为空 |

## 循环节点 (Loop)

### 节点信息

| 属性 | 值 |
|------|-----|
| 节点类型 | `loop` |
| 所属 Domain | `common` |
| 节点分类 | 逻辑类 |

### 输入端口

| 端口名称 | 端口类型 | 是否必填 | 说明 |
|----------|----------|----------|------|
| input | data | 是 | 输入数据 |
| trigger | trigger | 是 | 触发信号 |

### 输出端口

| 端口名称 | 端口类型 | 说明 |
|----------|----------|------|
| output | data | 循环输出 |
| complete | trigger | 循环完成信号 |

### 参数配置

| 参数名称 | 类型 | 默认值 | 说明 | 校验规则 |
|----------|------|--------|------|----------|
| loopType | enum | `count` | 循环类型 | `count`, `while`, `foreach` |
| count | number | `1` | 循环次数 | 必须大于 0 |
| condition | string | - | 循环条件 | 可选 |

## 使用示例

```json
{
  "id": "node-if-001",
  "type": "if-else",
  "name": "条件判断",
  "config": {
    "condition": "accuracy > 0.9"
  }
}
```

```json
{
  "id": "node-loop-001",
  "type": "loop",
  "name": "循环",
  "config": {
    "loopType": "count",
    "count": 5
  }
}
```
